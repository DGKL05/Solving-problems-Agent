Key Decisions Made

  • Agent-first, not solver-first — conversational commands are the core UX
  • Command-driven: "加入错题集", "复习", "类似题目" via LangChain tools
  • Qwen-Max + 阿里云 OCR — two-step pipeline, not multimodal
  • Flat 错题集 with tags (subject, difficulty, error_type, timestamp)
  • ACM + Math focus — code generation + algorithm analysis capability
