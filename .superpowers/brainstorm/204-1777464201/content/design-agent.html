Design Section 2: Agent Core

LangChain Tool-Calling with Qwen Function Calling

Agent Architecture

Tool Definitions

solve_problem

Params: imageUrl, subjectType (ACM/MATH/408)

Flow: 调用 image-pipeline OCR → 清洗文本 → Qwen-Max 解题

add_to_mistakes

Params: problemId, tags[], errorType, notes

Flow: 保存到 MySQL mistake_collections 表

query_mistakes

Params: tag, dateRange, page, limit

Flow: 从 MySQL 查询错题列表 + 统计

recommend_similar

Params: problemId, count

Flow: 基于标签匹配推荐同类错题

explain_concept

Params: concept, subjectType

Flow: Qwen-Max 直接解释概念 + 举例

Prompt 策略

System Prompt

Agent 身份设定
工具描述
记忆格式指令

Subject Prompts

ACM: 代码+复杂度
Math: 分步推导
408: 概念+计算+画图

Memory

Redis: 当前会话全文
MongoDB: 历史摘要

调用流程

用户: "帮我解这道题" (拍照上传图片)

Agent: 判断subjectType → call solve_problem → Qwen-Max 根据subject prompt解题 → 返回结果

用户: "加入错题集"

Agent: Qwen function calling 识别意图 → call add_to_mistakes → 确认保存成功 + 标签建议

用户: "昨天做错的那几道题"

Agent: 从 Redis 获取会话上下文 → call query_mistakes(yesterday) → 返回列表
