Design Section 3: Data Model

MySQL Tables + Schemas

MySQL Table Design
users
id (BIGINT PK)
openid (VARCHAR UNIQUE) — 微信 OpenID
nickname (VARCHAR)
avatar_url (VARCHAR)
created_at (DATETIME)
last_active_at (DATETIME)
problems
id (BIGINT PK)
user_id (BIGINT FK → users)
subject_type (ENUM: ACM / MATH / CS408)
ocr_raw_text (TEXT) — OCR 原始结果
cleaned_text (TEXT) — 清洗后文本
original_image_url (VARCHAR)
solution_text (TEXT) — AI 生成的解答
solution_code (TEXT) — 代码（仅 ACM）
tags (JSON) — 用户选择的标签
error_type (VARCHAR) — 错因分类（仅错题时）
created_at (DATETIME)
mistake_collections
id (BIGINT PK)
user_id (BIGINT FK → users)
problem_id (BIGINT FK → problems)
added_from_session_id (VARCHAR) — 来源会话
memo (TEXT) — 用户备注
review_count (INT DEFAULT 0)
last_reviewed_at (DATETIME)
created_at (DATETIME)
tags
id (BIGINT PK)
user_id (BIGINT FK → users)
name (VARCHAR)
color (VARCHAR) — 可选
problem_tags (多对多)
problem_id (BIGINT FK → problems)
tag_id (BIGINT FK → tags)
MongoDB Collections

chat_sessions

  • session_id
  • user_id
  • messages[]
  • summary (跨会话摘要)
  • created_at

images

  • image_id
  • user_id
  • file_data (GridFS)
  • ocr_text
  • created_at
