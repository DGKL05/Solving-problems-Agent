Design Section 1: System Architecture

Spring Boot Modular Monolith — LangChain Tool-Calling

Module Structure

agent-dome (父 POM)

agent-core

LangChain 工具定义 + Function Calling 编排 + 对话管理

image-pipeline

图片上传 → 阿里云OCR → 文本清洗 → 结构提取

mistake-service

错题集 CRUD + 标签管理 + 查询推荐

user-service

微信 OpenID 认证 + 用户资料

gateway (API)

统一 REST API + WebSocket 入口

数据层分配

MySQL
  • users
  • problems (题目)
  • mistake_collections
  • tags
  • problem_tags
Redis
  • Active session memory (TTL)
  • Conversation context
  • Rate limiting
MongoDB
  • Original images
  • OCR raw results
  • Historical chat logs
  • Session summaries

关键流程

1. 拍照解题: 小程序拍照 → 上传到后端 → image-pipeline OCR → agent-core 调用 Qwen-Max 解题 → 返回结果到小程序

2. 加入错题集: 用户说"加入错题集" → LangChain function calling 触发 add_to_mistakes → mistake-service 保存到 MySQL

3. 跨会话记忆: 会话结束 → agent-core 生成摘要 → 存入 MongoDB → 下次会话加载摘要到 Redis
