Design Section 4: Image Pipeline

Upload → OCR → Clean → Solve

Pipeline Flow

小程序拍照/选图 →

↓ 上传 → Spring Boot 接收 → 存入 MongoDB (GridFS) → 返回 imageId

↓ 阿里云OCR → 异步回调 / 同步等待结果 → 获取原始文本

↓ 文本清洗 → 去除噪声行 → 识别题目文本段 → 保留公式/代码格式

↓ Qwen-Max → 按 Subject 调用对应 prompt 解题

↓ 返回小程序 → 解答 + 代码（如有）

技术要点

上传

小程序 wx.uploadFile
→ 后端 MultipartFile
→ MongoDB GridFS

OCR

阿里云 OCR API
→ 识别文字/公式
→ 返回带坐标的文本段

清洗

去除页眉页脚
合并文本段落
保留代码缩进

异常处理

  • OCR识别率低: 返回原文图片 + 部分文本，让模型尝试推断
  • 图片模糊: 提示用户重拍，建议保持光线充足
  • 多页题目: 目前按单图处理，后续支持批量
  • 超时: 异步处理 + 轮询结果
